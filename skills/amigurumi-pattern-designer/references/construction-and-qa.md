# Construction and QA Reference

## 1. Model the subject as simple forms

Use simple crochet primitives before adding detail:

- Sphere or ellipsoid: head, cheeks, rounded body.
- Tapered cylinder: arms, legs, necks, tails.
- Cone: snouts, horns, pointed ears, hats.
- Flattened oval/disk: ears, eye patches, paw pads, wings.
- Cup: muzzle, shell, open mouth, hood.
- Flat shaped piece: fins, leaves, appliques.

Write down the intended proportion of each part relative to the total height. This catches oversized heads, undersized limbs, and misplaced facial features before stitch instructions are written.

## 2. Single-crochet shaping heuristics

For common spiral amigurumi in single crochet:

- A flat circle often begins with 6 sc in a magic ring and increases by about 6 stitches per full increase round.
- A rounder sphere typically uses several increase rounds, one or more even rounds near maximum circumference, then corresponding decrease rounds.
- More even rounds create a longer capsule/ellipsoid; fewer create a flatter or rounder form.
- A tapered cylinder changes count gradually rather than in one large jump.
- Stagger increase/decrease positions between rounds to reduce visible corners.

These are heuristics, not physical guarantees. Yarn thickness, stitch height, tension, stuffing density, and fiber behavior affect the result.

## 3. Plan size from gauge when available

If gauge is available, use it to estimate dimensions:

- Approximate circumference = maximum stitch count / stitches-per-unit-width.
- Approximate crocheted height = worked rounds / rounds-per-unit-height.

Treat these as pre-stuffing estimates. Stuffing can enlarge width and shorten/round the apparent height.

If gauge is unavailable, give a target size as approximate and make the assumed yarn weight/hook combination explicit.

## 4. Facial and limb placement

Define placement relative to stable landmarks:

- Use round numbers for vertical placement.
- Use stitch spacing for horizontal placement.
- State whether positions are measured from the beginning-of-round marker, center front, or another landmark.
- For symmetrical features, specify center-to-center spacing or equal offsets from center front.
- Re-evaluate placement after stuffing; stuffed geometry can shift apparent positions.

For eyes, ears, arms, and legs, avoid instructions like "place where it looks right" unless the user explicitly wants freeform assembly.

## 5. Color changes

For each color-change round:

1. Break the round into contiguous segments.
2. Count every segment.
3. Confirm segment totals equal the full round stitch count.
4. State how to carry, cut, or rejoin yarn when it affects finish quality.

## 6. Stuffing and closure

- State when to begin stuffing before the opening becomes too small.
- Add stuffing gradually to avoid lumps.
- Keep narrow joints less densely stuffed if articulation or easier sewing is desired.
- Give a clear closing method for final small openings.

## 7. Assembly QA

Before finalizing:

- Confirm every separately crocheted part appears in assembly instructions.
- Confirm long sewing tails are requested where needed.
- Ensure left/right parts are aligned to the same landmarks unless intentional asymmetry is part of the design.
- Ensure embroidered details are added at a stage when the inside remains accessible if that makes finishing easier.

## 8. Difficulty calibration

Beginner:
- Favor sc, inc, dec, simple color changes, and separate sewn parts.
- Minimize short rows, complex surface crochet, and frequent mid-round color changes.

Intermediate:
- Allow invisible decreases, BLO/FLO shaping, joined components, moderate colorwork, and simple embroidery.

Advanced:
- Allow irregular shaping, offset rounds, short rows, complex colorwork, sculptural surface crochet, and precise asymmetrical construction.

## 9. Final consistency checklist

Verify all of the following:

- Each round's input stitches are fully consumed unless intentionally partial.
- Each repeat expands to the stated stitch total.
- The resulting count becomes the next round's starting count.
- Repeated identical rounds are clearly ranged, e.g. R8-12.
- Symmetrical parts match.
- Color segment totals match the round total.
- Placement references point to rounds that actually exist.
- Materials are used consistently.
- Hook size, yarn weight, and gauge assumptions do not contradict the target size.
- Language-specific abbreviations are defined once and used consistently.
