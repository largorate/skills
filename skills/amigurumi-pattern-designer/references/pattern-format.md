# Default Pattern Format

Use this structure for a complete standalone pattern unless the user requests something else.

# [Pattern name]

## Pattern overview
- Finished size: [approximate dimensions]
- Difficulty: [beginner/intermediate/advanced]
- Construction: [spiral/joined rounds/rows; sewn/joined parts]
- Terminology: [US / UK / Danish / other]

## Materials
- Yarn: [weight/fiber/colors/estimated quantity when defensible]
- Hook: [size]
- Stuffing: [type]
- Notions: [marker, tapestry needle, embroidery thread, optional eyes, etc.]

## Gauge
State gauge if supplied or intentionally designed around one. For typical small amigurumi where exact gauge is less important, say that tight, gap-free fabric is the priority and finished size is approximate.

## Abbreviations
Define every abbreviation used in the pattern, including increase/decrease semantics and whether invisible decreases are used.

## Notes
State:
- spiral vs joined rounds,
- whether turning chains count,
- color-change method if relevant,
- stuffing assumptions,
- any special stitch instructions.

## Parts

### Head
`R1: ... (6)`
`R2: ... (12)`
...

After the crochet rounds, place part-specific stuffing, eye placement, embroidery, and finishing notes.

Repeat for body, limbs, ears, muzzle, tail, accessories, etc.

## Assembly
Give a deterministic order. Use round/stitch landmarks for placement when possible.

## Final shaping and finishing
Explain final stuffing adjustment, embroidery, blocking only if appropriate, and hiding yarn ends.

## Validation note
Use one of these truthful statements:

- `Stitch counts were machine-checked for all countable shaped rounds.`
- `Stitch counts were checked manually; this pattern contains construction that was not fully representable in the bundled validator.`

Do not claim machine validation unless the script actually ran successfully.

## Repeat notation

Prefer compact notation when it remains unambiguous:

- `(sc, inc) x 6 (18)`
- `(3 sc, dec) x 6 (24)`
- `sc around (24)`

For mixed segments, ensure the arithmetic is obvious. If a round cannot be understood reliably from compact notation, write the segments explicitly.
